02

AI・開発

2024年から京都大学人工知能研究会（KAIRA）に所属し、RAGやエージェントAIなど、AIを活用した学術情報システムの実験・実装に取り組んでいます。ハッカソン等にも参加し、実装経験を積んできました。

  1. 01 2024年秋・KAIRA 学園祭展示

    シラバスRAG検索システム

    大学のシラバスを検索・要約できるRAG（検索拡張生成）システム。実験・実装を担当し、初のAIシステム開発に。会誌にはレトリーバーの実装と実験結果に関する技術記事を執筆しました。

    • RAG
    • Retriever
    • 技術記事執筆

    会誌2024｜レトリーバー実装の技術記事（PDF） ↗

  2. 02 2025年春・KAIRA ハッカソン

    生成AIタスク管理アプリ

    Streamlit / Google Tasks API / Gemini API を用いたタスク管理アプリ。優先度付け関数とタスクソート機能を実装し、初めてGitHubでのチーム開発を経験しました。

    • Streamlit
    • Google Tasks API
    • Gemini API
    • GitHub
  3. 03 2025年秋・学園祭

    シラバス Agentic AI システム

    Tree of Thoughts（ToT）などの推論フレームワークを用いた自律型エージェントによるシラバス検索システム。AIが自律的に推論・改善する学習支援の可能性を探る実験的プロジェクトです。

    • Agentic AI
    • Tree of Thoughts

    資料を見る（PDF） ↗

    salmonAI

    AIと振り返るタイムブロッキングアプリ（タスク管理 × AI）。Big Five を用いたモックデータで自己理解を深めながら、行動量を上げることを目指します。Google Developer Group on Campus 2026 で制作。

    • タイムブロッキング
    • Big Five
